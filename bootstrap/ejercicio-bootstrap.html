🎯 Ejercicio Práctico: Tarjeta Bootstrap

Crea una tarjeta de presentación profesional usando Bootstrap

🎯Objetivo del Ejercicio

Vamos a crear una tarjeta de presentación personal utilizando únicamente clases de Bootstrap. El resultado debe ser responsive y visualmente atractivo.

📋 Requisitos:

  • ✅ Usar el sistema de grid de Bootstrap
  • ✅ Implementar una tarjeta con .card
  • ✅ Incluir botones con diferentes estilos
  • ✅ Aplicar utilidades de espaciado y color
  • ✅ Hacer el diseño responsive
  • ✅ Usar al menos 10 clases de Bootstrap

📝Guía Paso a Paso

1 Estructura HTML Básica

Comienza creando la estructura HTML básica con Bootstrap CDN:

📄 index.html 
<!DOCTYPE html>
<html lang="es">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Mi Tarjeta de Presentación</title>
        <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
    </head>
    <body>
        <!-- Aquí irá tu contenido -->
        <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
    </body>
</html>

2 Crear el Contenedor y Grid

Usa el sistema de grid de Bootstrap para centrar la tarjeta:

📄 index.html 
<body class="bg-light py-5">
    <div class="container">
        <div class="row justify-content-center">
            <div class="col-md-8 col-lg-6">
                <!-- Aquí irá la tarjeta -->
            </div>
        </div>
    </div>
</body>

3 Estructura de la Tarjeta

Crea la estructura básica de la tarjeta con header, body y footer:

📄 index.html 
<div class="card shadow-lg border-0">
  <div class="card-header bg-primary text-white text-center py-4">
    <!-- Avatar y título -->
  </div>
  <div class="card-body p-4">
    <!-- Contenido principal -->
  </div>
  <div class="card-footer bg-light text-center">
    <!-- Información adicional -->
  </div>
</div>

4 Header con Avatar y Título

Agrega un avatar (emoji) y el nombre en el header:

📄 index.html 
<div class="card-header bg-primary text-white text-center py-4">
    <div class="bg-white rounded-circle d-inline-flex align-items-center justify-content-center mb-3" 
                style="width: 80px; height: 80px;">

    </div>

</div>

🎨Ideas para Personalizar

🎯 Cambios de Color

  • • Cambia .bg-primary por .bg-success, .bg-danger, etc.
  • • Experimenta con .text-primary, .text-warning
  • • Usa .bg-gradient para fondos con gradiente
  • • Prueba .border-primary para bordes de color

📱 Responsividad

  • • Cambia .col-md-8 por otros tamaños
  • • Usa .d-md-block .d-none para mostrar/ocultar
  • • Prueba .text-md-start .text-center
  • • Experimenta con .flex-md-row .flex-column

✨ Efectos Visuales

  • • Añade .shadow-sm, .shadow-lg
  • • Usa .rounded-pill para bordes redondeados
  • • Prueba .border-0, .border-3
  • • Experimenta con .opacity-75

🧩 Componentes Extra

  • • Agrega .badge para etiquetas
  • • Incluye .progress para barras de progreso
  • • Usa .list-group para listas
  • • Añade iconos con Bootstrap Icons
