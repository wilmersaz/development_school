🌐 Fetch API

La interfaz moderna de JavaScript para realizar peticiones HTTP

📚 ¿Qué es Fetch API?

Definición

Fetch API es una interfaz moderna de JavaScript que proporciona una forma poderosa y flexible de realizar peticiones HTTP de manera asíncrona. Es el reemplazo moderno de XMLHttpRequest.

💡 Características clave:

  • • Basado en Promises
  • • Sintaxis más limpia y legible
  • • Soporte nativo en navegadores modernos
  • • Manejo de respuestas más intuitivo

Comparación: XMLHttpRequest vs Fetch

❌ XMLHttpRequest (Antiguo)
var xhr = new XMLHttpRequest();
xhr.open('GET', '/api/data');
xhr.onreadystatechange = function() {
  if (xhr.readyState === 4) {
    if (xhr.status === 200) {
      console.log(xhr.responseText);
    }
  }
};
xhr.send();
✅ Fetch API (Moderno)
fetch('/api/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));

⚡ Sintaxis Básica

Estructura básica de fetch()

fetch(url, options)
  .then(response => {
    // Procesar la respuesta
    return response.json(); // o response.text(), response.blob(), etc.
  })
  .then(data => {
    // Trabajar con los datos
    console.log(data);
  })
  .catch(error => {
    // Manejar errores
    console.error('Error:', error);
  });

Parámetros de fetch()

url: La URL del recurso que quieres obtener

options: (Opcional) Objeto con configuraciones como método, headers, body, etc.

Valor de retorno

Retorna una Promise que se resuelve con un objeto Response

La Promise se rechaza solo si hay un error de red

💻 Tu primer Fetch

Código JavaScript

// Petición GET simple
fetch('https://jsonplaceholder.typicode.com/posts/1')
  .then(response => {
    console.log('Status:', response.status);
    console.log('OK:', response.ok);
    return response.json();
  })
  .then(post => {
    console.log('Título:', post.title);
    console.log('Contenido:', post.body);
  })
  .catch(error => {
    console.error('Error:', error);
  });

¿Qué hace este código?

1. Hace una petición GET
A la API de JSONPlaceholder
2. Verifica la respuesta
Muestra el status y si fue exitosa
3. Convierte a JSON
Transforma la respuesta en un objeto JavaScript
4. Usa los datos
Muestra el título y contenido del post

¿Navegadores antiguos?

Internet Explorer no soporta Fetch API

Para navegadores antiguos, puedes usar:

  • • Polyfill: fetch polyfill de GitHub
  • • Alternativa: Axios o XMLHttpRequest
Polyfill CDN:
https://polyfill.io/v3/polyfill.min.js?features=fetch
