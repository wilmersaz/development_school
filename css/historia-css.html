📜La Evolución de CSS

Desde 1994 hasta la era moderna del diseño web

🌟 Los Inicios (1994)

El Problema Original

  • • HTML solo manejaba estructura y contenido
  • • Los estilos se mezclaban con el HTML
  • • Difícil mantenimiento de sitios web
  • • No había separación de responsabilidades

La Necesidad

Se necesitaba una forma de separar el contenido (HTML) de la presentación (estilos visuales).

HTML antes de CSS:

<font color="red" size="5">
  <b>Título Principal</b>
</font>
<p>
  <font color="blue" size="3">
    Texto del párrafo
  </font>
</p>

❌ Estilos mezclados con contenido

🎯 CSS1 (1996)

Características Principales

  • • Håkon Wium Lie propuso CSS
  • • Primera recomendación del W3C
  • • Propiedades básicas de fuente y color
  • • Modelo de cajas básico
  • • Selectores simples (elemento, clase, ID)

Impacto

Revolucionó el diseño web separando contenido y presentación.

Ejemplo CSS1:

/* CSS1 - 1996 */
H1 { 
  font-size: 24pt;
  color: red;
  font-weight: bold;
}

P {
  font-size: 12pt;
  color: blue;
  margin: 10px;
}

✅ Estilos separados del HTML

🚀 CSS2 (1998)

Nuevas Capacidades

  • • Posicionamiento (absolute, relative, fixed)
  • • Media types (screen, print, handheld)
  • • Selectores avanzados (descendente, hijo)
  • • Z-index para capas
  • • Pseudo-elementos y pseudo-clases

CSS2.1 (2004-2011)

  • • Corrección de errores de CSS2
  • • Eliminación de características no implementadas
  • • Mejor compatibilidad entre navegadores
  • • Base sólida para CSS3

Código CSS2:

.sidebar {
  position: absolute;
  top: 100px;
  left: 20px;
  width: 200px;
  z-index: 10;
}

@media print {
  .no-print { display: none; }
}

✨ CSS3 (2001-Presente)

Módulos Principales

  • • Selectors Level 3
  • • Media Queries
  • • Colors
  • • Backgrounds and Borders
  • • Text Effects
  • • Transforms

Nuevas Características

  • • Border-radius
  • • Box-shadow
  • • Gradients
  • • Animations
  • • Transitions
  • • Flexbox

CSS Moderno

  • • CSS Grid
  • • CSS Variables
  • • CSS Container Queries
  • • CSS Subgrid
  • • CSS Nesting
  • • CSS Layers

CSS3 Moderno:

.modern-card {
  background: linear-gradient(45deg, #ff6b6b, #4ecdc4);
  border-radius: 15px;
  box-shadow: 0 10px 30px rgba(0,0,0,0.3);
  transform: translateY(-5px);
  transition: all 0.3s ease;
}

.modern-card:hover {
  transform: translateY(-10px) scale(1.05);
}

@media (max-width: 768px) {
  .modern-card { transform: none; }
}
