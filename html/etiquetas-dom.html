📋 DOCTYPE: La Declaración Fundamental

¿Qué es DOCTYPE?

DOCTYPE (Document Type Declaration) le dice al navegador qué versión de HTML está usando el documento.

¿Por qué es importante?

  • • Activa el modo estándar del navegador
  • • Evita el modo de compatibilidad (quirks mode)
  • • Asegura renderizado consistente
  • • Permite validación del HTML

Evolución de DOCTYPE

HTML 4.01 Strict:

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
    "http://www.w3.org/TR/html4/strict.dtd">

XHTML 1.0:

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
    "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

HTML5 (Actual):

<!DOCTYPE html>

¡Simple y universal!

🏷️ Atributos de las Etiquetas

¿Qué son los Atributos?

Los atributos proporcionan información adicional sobre los elementos HTML. Se escriben dentro de la etiqueta de apertura.

Estructura:

<etiqueta atributo="valor">contenido</etiqueta>

• Nombre: Identifica el atributo
• Valor: Define el comportamiento (siempre entre comillas)

Atributos Globales

id

Identificador único del elemento

<div id="mi-elemento">

class

Clase(s) CSS para estilos

<p class="texto grande">

style

Estilos CSS inline

<span style="color: red;">

title

Tooltip al pasar el mouse

<img title="Mi imagen">

🎯 Atributos Específicos por Etiqueta

<img>

src - URL de la imagen
alt - Texto alternativo
width/height - Dimensiones

<a>

href - URL destino
target - Ventana destino
download - Descargar archivo

<input>

type - Tipo de entrada
name - Nombre del campo
value - Valor inicial

🌳 El DOM (Document Object Model)

Representación visual e interactiva del árbol de documentos

¿Qué es el DOM?

El Document Object Model (DOM) es una representación estructurada del documento HTML como un árbol de objetos que pueden ser manipulados con JavaScript.

Origen del concepto:

  • • 1990s: Netscape introduce el concepto
  • • 1998: W3C estandariza DOM Level 1
  • • 2000: DOM Level 2 (eventos, CSS)
  • • 2004: DOM Level 3 (XPath, validación)
  • • Presente: DOM Living Standard (WHATWG)

¿Para qué sirve?

  • • Acceder a elementos HTML desde JavaScript
  • • Modificar contenido dinámicamente
  • • Manejar eventos de usuario
  • • Crear aplicaciones web interactivas

Estructura de Árbol

Ejemplo HTML → DOM

<html>
  <head>
    <title>Mi Página</title>
  </head>
  <body>
    <h1>Hola Mundo</h1>
    <p>Párrafo de ejemplo</p>
  </body>
</html>

🌳 Conceptos Clave

Nodo: Cada elemento del árbol DOM
Padre: Elemento que contiene otros elementos
Hijo: Elemento contenido dentro de otro
Hermanos: Elementos al mismo nivel
Descendientes: Todos los elementos dentro de uno
Ancestros: Todos los elementos que contienen uno

⚡ Manipulación con JavaScript

// Seleccionar elemento
let titulo = document.getElementById('mi-titulo');

// Cambiar contenido
titulo.textContent = 'Nuevo título';

// Cambiar estilo
titulo.style.color = 'blue';

// Agregar evento
titulo.addEventListener('click', function() {
  alert('¡Hiciste clic!');
});
