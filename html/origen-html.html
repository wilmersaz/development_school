🌟 Los Inicios de HTML

Un viaje desde SGML hasta la revolución del HyperText

📜 Antes del HTML: SGML (1960s-1980s)

¿Qué era SGML?

  • • Standard Generalized Markup Language
  • • Desarrollado por IBM en los años 60
  • • Estándar ISO desde 1986
  • • Diseñado para documentos técnicos complejos
  • • Usado por gobiernos y grandes corporaciones
  • • Problema: Muy complejo y costoso de implementar

¿Por qué no funcionó para Internet?

  • • Requería software especializado y caro
  • • Curva de aprendizaje muy empinada
  • • No era adecuado para documentos simples
  • • Demasiado rígido para la web emergente

Ejemplo de SGML:

<!DOCTYPE documento [
  <!ELEMENT documento (titulo, contenido)>
  <!ELEMENT titulo (#PCDATA)>
  <!ELEMENT contenido (#PCDATA)>
]>
<documento>
  <titulo>Mi Documento</titulo>
  <contenido>Este es el contenido</contenido>
</documento>
Nota: Este ejemplo es simple, pero SGML real era mucho más complejo, con DTDs (Document Type Definitions) de cientos de líneas.

🖥️ Era de las Computadoras Aisladas (1950s-1970s)

El Mundo Antes de Internet

  • • Computadoras aisladas: Cada máquina era una isla
  • • Documentos locales: Solo veías lo que tenías en tu computadora
  • • Intercambio físico: Disquetes, cintas magnéticas, papel
  • • Colaboración limitada: Muy difícil compartir información
  • • Formatos incompatibles: Cada sistema tenía sus propios estándares

Problemas de la Era Pre-Internet

🏢

Trabajo en Silos: Cada departamento, universidad o empresa trabajaba aisladamente

📄

Duplicación: La misma información se recreaba una y otra vez

⏰

Lentitud: Compartir datos tomaba días o semanas

🌐 El Nacimiento de ARPANET (1969-1980s)

La Primera Red de Computadoras

ARPANET fue desarrollada por DARPA (Defense Advanced Research Projects Agency) del Departamento de Defensa de EE.UU. como respuesta al lanzamiento del Sputnik soviético en 1957.

Cronología de ARPANET:

1969: Primera conexión entre UCLA y Stanford
1971: Primer email enviado por Ray Tomlinson
1973: Primeras conexiones internacionales
1983: Adopción del protocolo TCP/IP

Limitaciones de ARPANET:

🔒 Acceso Restringido

Solo universidades y organizaciones de investigación

📝 Texto Plano

Solo se podía enviar texto simple, sin formato

🔧 Complejidad Técnica

Requería conocimientos técnicos avanzados

🚫 Sin Hiperenlaces

No existía forma de "saltar" entre documentos

El Problema que Persistía:

Aunque ARPANET permitía la comunicación entre computadoras, cada documento seguía siendo una isla. No había forma de conectar la información de manera intuitiva. Los usuarios tenían que saber exactamente dónde estaba cada archivo y cómo acceder a él.
