Y por qué NO es un lenguaje de programación

📝 ¿Qué es "Marcado"?

Concepto Histórico

📰 Origen Editorial

En las imprentas, los editores "marcaban" los manuscritos con anotaciones para indicar formato:

  • • Texto en negrita
  • • Texto en cursiva
  • • Tamaño de fuente
  • • Espaciado y márgenes

💻 En Computación

Los lenguajes de marcado usan etiquetas para definir la estructura y presentación del contenido.

Ejemplo Visual: Manuscrito Marcado

Mi Documento

← TÍTULO GRANDE
Este es un párrafo importante ← NEGRITA
Texto normal aquí... ← NORMAL
Texto enfatizado ← CURSIVA

Las anotaciones en rojo son las "marcas"

❌ ¿Por qué NO es Programación?

🔍 Diferencias Fundamentales

🚫 HTML NO tiene:

  • • Variables
  • • Bucles (for, while)
  • • Condicionales (if, else)
  • • Funciones
  • • Operaciones matemáticas
  • • Lógica de programación

✅ HTML SÍ tiene:

  • • Etiquetas descriptivas
  • • Estructura jerárquica
  • • Atributos informativos
  • • Semántica del contenido
  • • Enlaces a recursos

💡 Comparación Práctica

Lenguaje de Programación (JavaScript)

let contador = 0;
for (let i = 0; i < 5; i++) {
  contador += i;
  console.log(contador);
}

Ejecuta lógica, calcula, toma decisiones

Lenguaje de Marcado (HTML)

<h1>Título</h1>
<p>Párrafo de texto</p>
<img src="foto.jpg" alt="Foto">

Describe estructura, no ejecuta lógica

🌳 Jerarquía de Etiquetas

Estructura Jerárquica

HTML funciona como un árbol familiar, donde las etiquetas pueden contener otras etiquetas:

Terminología:

  • • Elemento padre: Contiene otros elementos
  • • Elemento hijo: Está dentro de otro elemento
  • • Elementos hermanos: Están al mismo nivel
  • • Anidamiento: Elementos dentro de elementos

🌲 Ejemplo Visual

<html> ← Raíz
  <head> ← Hijo de html
    <title>Mi Página</title>
  </head>
  <body> ← Hermano de head
    <h1>Título</h1> ← Hijo de body
    <p> ← Hermano de h1
      Texto con <strong>énfasis</strong>
    </p>
  </body>
</html>
