📅 Evolución de HTML

Las 7 versiones clásicas y la unificación en HTML5

1.0

HTML 1.0 (1991)

El primer borrador

Características:

  • • Solo 18 etiquetas básicas
  • • Estructura muy simple
  • • Sin formularios
  • • Sin tablas
  • • Solo texto e imágenes básicas

Etiquetas principales:

<title> <h1>-<h6> <p> <a> <ul> <li>
2.0

HTML 2.0 (1995)

Primera especificación estándar oficial

Novedades:

  • • Formularios básicos (<form>, <input>)
  • • Imágenes mejoradas (<img>)
  • • Caracteres especiales
  • • RFC 1866 como estándar

Ejemplo de formulario:

<form action="/enviar">
  <input type="text" name="nombre">
  <input type="submit" value="Enviar">
</form>
3.2

HTML 3.2 (1997)

Era del W3C y las tablas

Características:

  • • Tablas (<table>, <tr>, <td>)
  • • Applets de Java
  • • Scripts básicos
  • • Mapas de imagen
  • • Mejor soporte de formularios

Tabla básica:

<table border="1">
  <tr>
    <td>Celda 1</td>
    <td>Celda 2</td>
  </tr>
</table>
4.0

HTML 4.0 (1997)

Separación de contenido y presentación

Innovaciones:

  • • CSS integrado
  • • Marcos (frames)
  • • Mejor accesibilidad
  • • Internacionalización
  • • Objetos y scripts mejorados

Con CSS:

<link rel="stylesheet" 
      href="estilos.css">
<div class="contenedor">
  <p style="color: blue;">Texto</p>
</div>
4.01

HTML 4.01 (1999)

Corrección de errores

Mejoras:

  • • Corrección de bugs de HTML 4.0
  • • Mejor validación
  • • Especificación más clara
  • • Tres variantes: Strict, Transitional, Frameset

DOCTYPE variants:

• Strict: Más estricto
• Transitional: Permite elementos obsoletos
• Frameset: Para marcos
XHTML

XHTML 1.0 (2000)

HTML reformulado en XML

Reglas estrictas:

  • • Todas las etiquetas deben cerrarse
  • • Atributos entre comillas
  • • Elementos en minúsculas
  • • Estructura bien formada (XML)

Ejemplo XHTML:

<p>Párrafo con <br /> salto</p>
<img src="foto.jpg" alt="Foto" />
<input type="text" name="campo" />
1.1

XHTML 1.1 (2001)

Modularización

Características:

  • • Estructura modular
  • • Ruby annotations (texto asiático)
  • • Mejor internacionalización
  • • Eliminación de elementos presentacionales

Módulos:

• Core (básico)
• Tables (tablas)
• Forms (formularios)
• Image (imágenes)

🎯 2005: La Gran Unificación

HTML5 - El fin de la fragmentación

🤔 El Problema

Fragmentación:

  • • Múltiples versiones incompatibles
  • • XHTML vs HTML
  • • Reglas confusas y contradictorias
  • • Desarrolladores perdidos

Limitaciones:

  • • Sin soporte multimedia nativo
  • • Aplicaciones web limitadas
  • • Dependencia de plugins
  • • Falta de APIs modernas

✅ La Solución HTML5

Unificación:

  • • Una sola especificación
  • • Retrocompatibilidad total
  • • Sintaxis flexible
  • • Desarrollo continuo

Nuevas Características:

  • • Audio y video nativos
  • • Canvas para gráficos
  • • APIs de geolocalización
  • • Almacenamiento local
