🏛️ Los Guardianes de HTML

W3C y WHATWG: Historia, conflictos y colaboración

W3C

World Wide Web Consortium

Fundado en 1994 por Tim Berners-Lee

📋 Misión y Objetivos

  • • Desarrollar protocolos y estándares web
  • • Asegurar la compatibilidad entre navegadores
  • • Promover la accesibilidad web
  • • Fomentar la innovación responsable
  • • Mantener la web abierta y gratuita

🏢 Estructura

Miembros:

400+ organizaciones (Google, Microsoft, Apple, Mozilla, etc.)

Proceso:

Consenso por comités, proceso lento pero democrático

Estándares:

HTML, CSS, SVG, XML, Accesibilidad (WCAG)

⚔️ El Gran Conflicto (2004-2019)

La batalla por el control de HTML

W3C

Posición Tradicionalista

  • • XHTML 2.0: Ruptura total con HTML
  • • XML puro: Sintaxis estricta
  • • Proceso formal: Comités y consensos
  • • Visión académica: Teoría sobre práctica
WG

Posición Pragmática

  • • HTML5: Evolución de HTML
  • • Retrocompatibilidad: No romper la web
  • • Desarrollo ágil: Implementar y especificar
  • • Visión práctica: Lo que funciona en navegadores

📅 Cronología del Conflicto

2004

Ruptura Inicial

WHATWG se forma en respuesta a XHTML 2.0

2007

W3C Reconoce HTML5

W3C abandona XHTML 2.0 y adopta HTML5 de WHATWG

2014

Dos Estándares

W3C publica HTML5 "Snapshot", WHATWG mantiene "Living Standard"

2019

Reconciliación

W3C acepta que WHATWG mantenga el estándar HTML
