🏷️ Etiquetas Principales de Tablas

Conoce a fondo cada etiqueta y su función específica

<table> - El Contenedor Principal

📋 Descripción

La etiqueta <table> es el contenedor raíz que define el inicio y fin de una tabla HTML. Sin ella, no puede existir ninguna tabla.

🎯 Función Principal:

  • • Crear el contexto de tabla para el navegador
  • • Permitir que CSS aplique estilos específicos de tabla
  • • Habilitar propiedades como border-collapse
  • • Establecer el modelo de caja de tabla

💻 Sintaxis

// Estructura básica
<table>
// Todo el contenido de la tabla va aquí
<tr>...</tr>
</table>

Importante: Siempre debe contener al menos una etiqueta <tr>

<tr> - Filas de la Tabla

📏 Descripción

La etiqueta <tr> (Table Row) define cada fila horizontal en la tabla. Cada fila contiene una o más celdas.

🎯 Características:

  • • Define la estructura horizontal de la tabla
  • • Puede contener <td> o <th>
  • • Determina la altura de la fila
  • • Permite aplicar estilos a toda la fila

⚠️ Regla Importante:

Todas las filas deben tener el mismo número de celdas para mantener la estructura de la tabla.

🎨 Ejemplo Visual

Fila 1, Celda 1 Fila 1, Celda 2
Fila 2, Celda 1 Fila 2, Celda 2
Fila 3, Celda 1 Fila 3, Celda 2
<tr> ← Cada fila
<td>...</td>
</tr>

<td> - Celdas de Datos

📦 Descripción

La etiqueta <td> (Table Data) contiene los datos reales de cada celda en la tabla.

💡 Usos Comunes:

  • • Contener texto, números o fechas
  • • Mostrar imágenes o íconos
  • • Enlaces o botones
  • • Cualquier contenido HTML válido

🔧 Atributos Útiles:

colspan - Fusionar columnas
rowspan - Fusionar filas

🎯 Tipos de Contenido

<th> - Encabezados de Tabla

🏷️ Descripción

La etiqueta <th> (Table Header) define las celdas de encabezado que describen el contenido de las columnas o filas.

🌟 Beneficios:

  • • Accesibilidad: Lectores de pantalla
  • • SEO: Mejor comprensión para buscadores
  • • Estilo: Negrita y centrado por defecto
  • • Semántica: Significado claro

🔧 Atributo Importante:

scope - Define si es encabezado de columna o fila

⚖️ Comparación de Etiquetas

Etiqueta Propósito Contenido Estilo por Defecto
<table> Contenedor principal Otras etiquetas de tabla display: table
<tr> Define filas <td> o <th> display: table-row
<td> Celdas de datos Cualquier contenido HTML display: table-cell
<th> Encabezados Títulos de columnas/filas font-weight: bold
text-align: center

🎯 Ejemplo Completo en Acción

📝 Código HTML

📄 index.html 
// Tabla completa con todas las etiquetas
<table border="1">
  <tr>
    <th>Producto</th>
    <th>Precio</th>
    <th>Disponible</th>
  </tr>
  <tr>
    <td>Laptop Gaming</td>
    <td>$1,299</td>
    <td>Sí</td>
  </tr>
  <tr>
    <td>Monitor 4K</td>
    <td>$599</td>
    <td>No</td>
  </tr>
</table>
